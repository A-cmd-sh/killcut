# KillCut — FPSキル集 自動モンタージュ (for VALORANT)

動画フォルダを渡すだけで、キルシーンを切り出し、BGMのビートに合わせてつないだ `montage.mp4` を作るツールです。

- **キルログ（キルフィード）から、指定した名前のプレイヤーのキルだけを自動で切り出す**：フル試合の録画をそのまま入れられます。デスや味方のキルは除外し、連続キルは1カットにまとめます
- **BGMのビートに合わせてカットを切り替える**：曲をフォルダに入れるだけで使えます。複数の曲を入れると名前順につなぎます
- **キルログにモザイク**：かけるかどうかを選べます（スクリムの映像などに）
- 録画したファイルを後から解析するだけなので、ゲーム本体には一切触れません

> 本ツールは非公式のファンプロジェクトであり、Riot Games, Inc. とは一切関係がなく、同社の承認・後援を受けたものではありません。VALORANT は Riot Games, Inc. の商標です。

## 使い方（exe版）

1. [Releases](../../releases) から `KillCut-windows.zip` をダウンロードして展開する
2. **ffmpeg**をインストールする（最初の1回だけ）：PowerShellで `winget install Gyan.FFmpeg` を実行する
3. 1つのフォルダに動画を入れる。BGMを使う場合は曲（mp3/wav/m4a など）も同じフォルダに入れる
4. そのフォルダを `KillCut.exe` にドラッグ＆ドロップする（またはexeをダブルクリックしてから、フォルダを画面にドラッグする）
5. 質問に答える
   - **プレイヤー名**：キルを拾いたい名前。カンマ区切りで複数指定できる。空欄にすると、各クリップの一番音が激しい所を切り出す
   - **モザイク**：y にすると、キルログ部分にモザイクがかかる
   - **BGM**：n にすると、ゲーム音だけになる
6. フォルダの中に `montage.mp4` ができる

初回だけ、文字認識モデルのダウンロード（約100MB）があります。

## 使い方（Python版）

```
pip install -r requirements.txt
python montage.py "D:\clips\scrim" --name Shuma --mosaic
```

NVIDIAのGPUがある場合は、先にCUDA版のPyTorchを入れておくとキルログの解析が大幅に速くなります（手順は https://pytorch.org を参照）。

### 主なオプション

| オプション | 内容 |
|---|---|
| `--name 名前` | キルを拾うプレイヤー名（複数指定できる: `--name A --name B`） |
| `--pre 3.5` / `--post 1.2` | キルの何秒前から何秒後までを使うか |
| `--mosaic` | キルログにモザイクをかける |
| `--mosaic-style blur` | モザイクの代わりにぼかしにする |
| `--mosaic-region x0,y0,x1,y1` | 追加でモザイクをかける範囲（画面に対する比率、0〜1） |
| `--music a.mp3 b.mp3` | BGMを指定する（複数の曲をつなげられる） |
| `--no-music` | BGMを使わない |
| `--game-vol 0.35` | BGMを流している時のゲーム音の音量 |
| `--res 1080x1920` | 縦型動画にする（ショート・TikTok用） |
| `--detect-only` | キルの検出だけをして、結果を表示する |
| `--debug-feed` | 読み取ったキルログの画像を `_feed_debug` に保存する（範囲の調整用） |
| `--feed-region 0.68,0.06,0.995,0.40` | キルログが表示される範囲 |

すべてのオプションは `python montage.py -h` で確認できます。

## うまく検出できない時

- `--debug-feed --detect-only` で実行し、`_feed_debug` の画像にキルログが全部写っているか確認する。はみ出している場合は `--feed-region` を調整する
- 名前が読み取られない場合は `--ocr-scale 1.5`、誤検出が多い場合は `--match 0.85` を付ける
- 解析結果は `_montage_cache` に保存されるので、2回目以降（曲だけを変えた時など）はすぐに終わる
